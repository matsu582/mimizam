# 音声指紋生成の詳細アルゴリズム

本ドキュメントでは、mimizamの詳細アルゴリズムと設計について記します。

---

## 1. 音声指紋生成の概要

音声指紋システムでは、音声データから特徴的なパターンを抽出し、コンパクトなハッシュ値として格納します。このプロセスは以下の段階で構成されます：

### 基本処理フロー
1. **音声前処理**: サンプリングレート変換・正規化
2. **スペクトログラム生成**: STFT（短時間フーリエ変換）による周波数解析
3. **ピーク検出**: 局所最大値の抽出
4. **ハッシュ生成**: アンカー＋2ターゲットの三つ組から尺度不変ハッシュを作成

mimizamでは音声特性に応じてパラメータを最適化し、高精度かつ高速な処理を実現しています。

---

## 2. 詳細アルゴリズム

### (1) スペクトログラム生成
音声データを時間-周波数表現に変換します。

- **STFT（短時間フーリエ変換）**: 音声信号を小さな時間窓に分割し、各窓でフーリエ変換を実行
- **FFTサイズ**: 通常1024または2048サンプル（周波数分解能と時間分解能のトレードオフ）
- **ホップ長**: FFTサイズの1/4程度（時間分解能の調整）
- **窓関数**: ハニング窓またはハミング窓（スペクトル漏れの抑制）

**設計根拠:**
- Wang 2003の基本手法に基づく時間-周波数解析
- 音声特性に応じたパラメータ調整により精度向上

### (2) ピーク検出
スペクトログラムから局所最大値（ピーク）を検出します。

- **局所最大値検出**: 近傍の周波数・時間範囲内で最大となる点を抽出
- **近傍サイズ**: 通常3×3または5×5の範囲（ノイズ除去と精度のバランス）
- **閾値設定**: 動的または固定閾値によるノイズ除去
- **密度制御**: 過密なピークの間引き処理

**最適化ポイント:**
- 音声の複雑度やノイズレベルに応じた閾値調整
- ジャンル特性を考慮したピーク密度制御

### (3) ハッシュ生成（尺度不変方式）
検出されたピークから、速度変化・ピッチ変化に本質的に不変なハッシュ値を生成します。

- **三つ組方式**: 各ピークをアンカー A とし、時間順で後続する2つのターゲット T1, T2 を選ぶ（tA < t1 < t2）
- **ターゲット選択（件数ベース）**: アンカー直後の N 個を件数で選ぶ。均一な速度変化ではピークの相対順序が保たれるため、変換後も同じ三つ組が再現されやすい
- **尺度不変な特徴量**:
  - 時間比 `r = (t1 - tA) / (t2 - tA)` … 時間伸縮（速度変化）で不変
  - 周波数比 `log2(f1/fA)`, `log2(f2/fA)` … 乗法的ピッチ変化で不変
- **ハッシュ化**: 上記3量を量子化し1つの32bit整数へ詰め込む（`[時間比:8bit][周波数比1:12bit][周波数比2:12bit]`）。暗号学的ハッシュ（SHA-256等）は使用しない
- **量子化境界への頑健化**: 周波数比は近傍2ビンへソフト量子化し（1三つ組あたり最大4ハッシュ）、境界跨ぎでも一方が一致するようにする
- **サブビン精度**: ピーク周波数を放物線補間でサブビンに補正し、線形周波数グリッドの量子化誤差を抑える

**旧方式からの変更点:**
- 旧「アンカー＋1ターゲット」の `[f1:11][f2:11][Δt:10]`（絶対周波数・絶対時間差）方式は完全に置き換えられました
- ハッシュ自体が尺度不変になったため、照合時の time_scale/freq_scale ブルートフォース探索は不要になりました（マッチャは単一検索＋頑健直線回帰）
- **ハッシュ形式が変わるため、既存DBは再指紋化（楽曲の再登録）が必要です**

### (4) 実装における最適化

mimizamでは、より効率的で精度の高い指紋生成のために以下の最適化を実装しています：

#### 音声特性に応じたパラメータ調整
- **動的閾値**: 音声のノイズレベルに応じた検出閾値の自動調整
- **パラメータ選択**: 音声の複雑度やジャンルに基づく最適パラメータの選択
- **リアルタイム調整**: 処理中の音声特性変化への対応

#### 処理効率の向上
- **段階的処理**: 必要に応じた詳細解析の実行
